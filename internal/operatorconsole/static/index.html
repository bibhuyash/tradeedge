BEFORE EVERY SESSION

Daily preparation checklist

This checklist is guidance, not a readiness verdict. Use the offline inspection command to verify prepared artifacts. Only an operator can approve startup.

  1. Approve the exact-date calendar

    Generate from the reviewed source policy; reject holidays, missing dates and checksum mismatches.

    generate-calendar → calendar-check
  2. Build the bounded instrument universe

    Use the current instrument dump and accepted forward references. Never hand-edit provider tokens.

    generate-shadow-derivatives → build-shadow-bundle
  3. Verify external integrations

    Obtain fresh Telegram evidence and read-only Zerodha preflight under operator control. Never paste credentials into this console.

  4. Bind and inspect authorization

    Bind the exact commit, session date and verified artifacts. Preparation does not start a session.

    go run ./cmd/tradeedge-validation prepare-session -date YYYY-MM-DD -commit FULL_COMMIT -authorization PATH
  5. Operator review, then observation

    Obtain explicit approval, start the canonical SHADOW service and observe both underlyings through warmup. Stop on unknown or inconsistent state.

  6. Close and preserve evidence

    Only finalize an actual authorized session after a clean close. Mock snapshots do not qualify as real-market evidence.

    finalize-shadow-session
